Project Title: Django & Generative AI-Powered Web Application

Overview: Designed and built a full-stack web application using Python and Django,
          integrated with modern Generative AI and Large Language Model (LLM) capabilities 
          to deliver automated, smart user experiences.
          
Key Architecture & Modules:Developed modular backend structures including a custom user management system (accounts),
                           a real-time conversational interface (chat), and a dynamic prompt or workspace builder (project_creator).
                           Configured secure database models, API endpoints, views, and service layers to handle seamless communication 
                           between Django and external LLM/Gemini APIs.
                           
Tech Stack: Python, Django, GenAI / Google Gemini LLM integrations, SQLite/MySQL, Git, and GitHub.   
                           
Key Features & Implementation:Integrated LLM-driven workflows to automate content generation and interactive chat responses within the application.
                              Managed end-to-end version control using Git and maintained clean, production-ready source code hosted on GitHub.
